class plans.datasets.analyst.Bivar(name='MyBivar', alias='Bv0')[source]#

Bases: DataSet

The Bivariate object.

Holds a paired x/y sample in a pandas.DataFrame (sorted by x) and supports fitting simple regression models (see models attribute) and assessing their errors.

Examples

from plans.datasets.analyst import Bivar

bv = Bivar(name="StageDischarge", alias="SD")
bv.set_data(x=vct_h, y=vct_q)
bv.fit(model_type="Power")

# scatter with marginal histograms
bv.view(show=True)

# model panel
bv.view_specs["layout"] = "model"
bv.view_specs["model_type"] = "Power"
bv.view(show=True)
