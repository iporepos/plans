plans.stochastic.arma#

Trend, season and AR(1) memory model for synthetic series.

A series is the sum of a linear trend, a mean-zero seasonal term and an AR(1) remainder driven by Gaussian shocks. For steps \(t = 0, 1, \dots, n-1\):

\[x_t = \underbrace{b + a t}_{\text{trend}} + \underbrace{A (g_t - m_k)}_{\text{season}} + R_t, \qquad R_t = \varphi R_{t-1} + \varepsilon_t, \qquad \varepsilon_t \sim \mathcal{N}(0, \sigma^2)\]

Parameters map to symbols as start \(b\), slope \(a\), amplitude \(A\), period \(P\), phase \(t_0\), power \(k\), phi \(\varphi\) and sigma \(\sigma\). Functions take plain arrays and an integer period (steps per cycle), so they know nothing about dates or units.

Three operations link observed data, parameters and synthetic data: fit_params() goes from data to parameters, decompose() splits data into components given the parameters, and build() makes a series from parameters.

plans.stochastic.arma.simulate_ar1(n, phi, sigma, rng)[source]#

Simulate an AR(1) remainder that is stationary from the first step.

The first shock is scaled to the stationary variance instead of discarding a burn-in. Draws therefore stay aligned when phi changes, so the same generator state isolates the effect of phi.

\[R_0 = \frac{\varepsilon_0}{\sqrt{1 - \varphi^2}}, \qquad \mathrm{Var}(R_t) = \frac{\sigma^2}{1 - \varphi^2}\]
Parameters:

  • n (int) – number of steps

  • phi (float) – AR(1) memory, inside (-1, 1)

  • sigma (float) – shock standard deviation

  • rng (numpy.random.Generator) – random generator

Returns:

remainder

Return type:

plans.stochastic.arma.fit_params(x, period)[source]#

Fit the model to a series.

Trend and season are fitted jointly by nonlinear least squares from several starting shapes, keeping the best. power is bounded by POWER_MIN and POWER_MAX, so a season with a sharp trough and a flat top cannot be represented.

Memory and shocks come from the remainder \(R_t\), after removing its mean. The memory is a regression through the origin, and \(\hat{\sigma}\) is the standard deviation of the residuals of that regression:

\[\hat{\varphi} = \frac{\sum_t R_{t-1} R_t}{\sum_t R_{t-1}^2}, \qquad \hat{\sigma} = \mathrm{sd}\left( R_t - \hat{\varphi} R_{t-1} \right)\]

Warning

Trend and season estimates ignore the memory, so they are less precise than they could be, and phi tends to be low on short series.

Parameters:

  • x (numpy.ndarray) – series without nan values

  • period (int) – steps per cycle

Returns:

parameters. Keys: start, slope, amplitude, period, phase, power, phi, sigma

Return type:

dict

plans.stochastic.arma.describe(params, n, positive=False)[source]#

Get a printout with all views of the same model.

Baseline and topline are the extremes of the deterministic cycle, at the trend average \(\bar{T}\). Noise moves the observed extremes beyond them.

\[\text{baseline} = \bar{T} - A m_k, \qquad \text{topline} = \bar{T} + A (1 - m_k)\]
Parameters:

  • params (dict) – parameters. See fit_params().

  • n (int) – number of steps, used by the views that depend on the length

  • positive (bool) – set True for variables that must stay positive. It warns if the deterministic floor is below zero.

Returns:

plans.stochastic.arma.make_params(period, start=None, average=None, slope=None, end=None, cycle_change=None, n=None, amplitude=None, baseline=None, topline=None, phase=0.0, power=1.0, phi=0.0, sigma=0.0)[source]#

Make the parameters from what is known, converting to the stored form.

The trend level comes from start or average, its change from slope, end or cycle_change, and the season from amplitude or from both baseline and topline, with \(A = \text{topline} - \text{baseline}\). Giving more than one option for the same item raises an error. Length-based conversions apply once here, so a longer series continues the same line.

See start_from_average(), slope_from_end() and slope_from_cycle_change() for the formulas.

Parameters:

  • period (int) – steps per cycle

  • start (float) – trend value at step 0

  • average (float) – trend average over the record. Requires n.

  • slope (float) – trend change per step

  • end (float) – trend value at the last step. Requires start and n.

  • cycle_change (float) – trend change per cycle

  • n (int) – number of steps, used only by the length-based conversions

  • amplitude (float) – peak-to-trough range of the seasonal term

  • baseline (float) – lowest value of the deterministic cycle

  • topline (float) – highest value of the deterministic cycle

  • phase (float) – step at which the season peaks

  • power (float) – shape

  • phi (float) – AR(1) memory, inside (-1, 1)

  • sigma (float) – shock standard deviation

Returns:

parameters. See fit_params().

Return type:

dict
