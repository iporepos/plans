get_nbins_fd(data)

This function computes the number of bins for histograms using the Freedman-Diaconis rule, which takes into account the interquartile range (IQR) of the sample, in addition to its range.

get_nbins_scott(data)

This function computes the number of bins using the Scott rule, which is similar to the Freedman-Diaconis rule, but uses the standard deviation of the data to compute the bin runsize.

get_nbins_sturges(data)

This function computes the number of bins using the Sturges rule, which assumes that the data follows a normal distribution and computes the number of bins based on its data runsize.

plans.stochastic.binning.classify(data, bins=None, n_classes=5, scheme='equal')[source]#

Classifies a 1D NumPy array into 0-indexed bins based on provided bin boundaries.

Values x are assigned to class i if bins[i] <= x < bins[i+1]. Values below bins[0] are assigned to class 0. Values at or above bins[-1] are assigned to the last class (len(bins) - 2).

Parameters:

  • data (numpy.ndarray) – The 1D NumPy array to classify.

  • bins (numpy.ndarray) – A 1D NumPy array specifying the sorted bin edges. Must contain at least two elements. If None, it is computed from the data.

  • n_classes (int) – number of classes, used only if bins is None

  • scheme (str) – scheme code, used only if bins is None. See get_bins().

Returns:

A 1D NumPy array of integers representing the 0-indexed class for each element in data.

Return type:

numpy.ndarray
