plans.stochastic.bayes.get_likelihood(evidence, weights, grid, baseline)[source]#

Get the likelihood on a hypothesis grid from a weighted evidence histogram.

Parameters:

  • evidence (numpy.ndarray) – vector of evidence values

  • weights (numpy.ndarray) – vector of evidence weights

  • grid (numpy.ndarray) – hypothesis grid, used as histogram edges

  • baseline (float) – value added to every grid point, so none has zero likelihood

Returns:

normalized likelihood, same size as grid

Return type:

numpy.ndarray
